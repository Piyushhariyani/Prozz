How it works

Learn about the analysis pipeline and scoring system.

Step 1 — Upload

Upload any .py Python file using the Review tab. Files are processed server-side and never stored permanently.

Step 2 — Syntax Check

The file is parsed using Python's built-in ast module. If parsing fails, a syntax error is reported with the exact line and message.

Step 3 — AST Analysis

A full Abstract Syntax Tree is walked to extract classes, functions, imports, and structural metrics like nesting depth and complexity.

Step 4 — Rule Check

Static lint rules are applied to detect common issues — missing docstrings, unused variables, overly long functions, and naming conventions.

Step 5 — LLM Feedback

The code and analysis results are sent to a large language model which generates human-readable feedback, suggestions, and improvement tips.

Step 6 — Scoring

A final score out of 100 is calculated from syntax validity (30%), rule compliance (30%), structural quality (20%), and LLM sentiment (20%).
